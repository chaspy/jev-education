# 誤概念分類ベンチマーク

2026-09-20に jev-1.13.0 で実測。公開データでは **Top-1 58.3%、Top-3 79.5%**。
保留しなかった89件では72件一致（80.9%）で、17件の誤分類が残った。
これは原データのラベルとの一致率であり、復習先の正しさや学習効果の評価ではない。

## 公開データ MaE

[著者のデータ公開リポジトリ](https://github.com/nancyotero-projects/math-misconceptions)
のコミット `12bee142d49dfb3c874149035cfbad28547a818b` を使用。
[論文](https://arxiv.org/abs/2412.03765)。MIT、Copyright 2024 Nancy Otero。
原データとライセンスを `data/mae-source.json`、`data/MAE-LICENSE` に同梱。
研究用に作られた英語の誤答例であり、日本の生徒の実答案を収集したデータではない。

全220例・55誤概念から画像を参照する39例を機械的に除外し、181例を採用。
問題文を正規化してハッシュ化し、同一問題が分割をまたがらないよう dev 30件 / test 151件に固定。
類似問題や同じ誤概念は両方に存在し得る。モデルの事前学習への混入は確認できない。
候補は全55ラベル。testには47ラベルが出現する。

入力は問題・誤答・模範解答のみ。正解ラベル、元の解説、トピックは入力しない。
55ラベルの定義を候補に渡すゼロショット分類で、トピックによる候補制限も行わない。
プロンプト、候補順、保留基準を実行前に固定し、この測定結果で調整していない。
devを使ったのは多数派ベースラインのみ。元論文とは評価条件が異なるためスコアを直接比較しない。

| 手法 | Top-1 | Top-3 | Macro F1 | 回答率 | 回答した分の一致率 |
|---|---:|---:|---:|---:|---:|
| Jev | 58.3% (88/151) | 79.5% (120/151) | 0.561 | 58.9% (89/151) | 80.9% (72/89) |
| TF-IDF候補定義との類似度 | 7.9% | 11.3% | 0.048 | 100% | 7.9% |
| devの最多ラベル | 0.7% | 3.3% | 0.00028 | 100% | 0.7% |

Top-1/3は保留した例も含む全件の順位で計算。Macro F1はtestに出現する47ラベルの平均。
保留はconfidence < 0.5 または最大候補確率 < 0.65。確率の校正済みを意味しない。
ベースラインは単純な比較用で、他の強力なモデルより優れることを示さない。
Top-1のWilson 95%区間は50.3–65.8%。問題間の相関を考慮しない参考値。

API往復の中央値223ms、p95 304ms。入力349,468 tokens、推定合計 **$0.014677656**。
入力100万tokensあたり$0.042、出力無料で算出。ローカルからの直列測定であり、画面全体の所要時間ではない。

## 日本語デモの回帰確認

既存3問題について作成した36答案。期待値はAI補助で作成した独自ラベルで、教科専門家によるレビュー前。
独立した汎化性能のベンチマークとは分けて扱う。実際のアプリのリクエスト生成・保留処理を使用した。
正答、途中答案、符号・分配・移項等の誤り、情報不足、入力内の指示文を含む。

| 手法 | Top-1 | 回答率 | 回答した分の一致率 |
|---|---:|---:|---:|
| Jev | 100% (36/36) | 72.2% (26/36) | 100% (26/26) |
| 単純な式パターン照合 | 66.7% (24/36) | 41.7% (15/36) | 100% (15/15) |

保留すべき9例は9例とも保留。さらに1例も確率によって保留された。
この小規模・既知問題での100%を、本番の精度とは解釈しない。
中央値225ms、p95 320ms、推定合計 **$0.002301222**。両測定合計は **$0.016978878**。
自作回帰データはCC BY 4.0（詳細はJSONのメタデータ）。

## 誤りの読み方と次の評価

- MaE45-ex1「ある数より3小さい」を `3-x` とした例は、正解ラベルMaE45に対してMaE33。
  両ラベルの定義は減算の順序に関して重なり、confidence 0.96でも保留されなかった。
  定義の曖昧さとモデルの誤分類を分けて教科担当者が確認する必要がある。
- MaE28-ex2は、比を `35 and 25` とした誤答を「比を関係として理解していない」ではなく
  「同値な比の理解」と分類し、保留しなかった。誤答から原因を一意に特定できるとは限らない。
- 原データMaE03-ex3の `5^-2` の正答が `0.05` とされている（計算上は0.04）など、
  元の模範解答にも不整合がある。今回、成績を見て行を除いたりラベルを書き換えたりしていない。
- MaEは誤答案だけなので、「正答を誤概念扱いする率」は測れない。日本語回帰での確認は限定的。

今回確かめたのは誤概念候補の分類まで。単元の依存関係と、選んだ教材で理解が改善するかは未検証。
次は別問題の日本語答案に教科担当者が複数の許容ラベル・確認問題・復習先を付ける。
ラベル付けの一致度と候補Top-3、不要な復習誘導率を確認し、その後に再挑戦の改善率を測る。

## 再実行

```sh
npm ci
npm run benchmark:prepare  # 同梱原本から分割を再生成。API不要
npm test                 # 分割・ラベル漏洩・集計を含む。API不要
# .env に TYPESAFE_API_KEY を設定。以下は実APIを呼び課金される
npm run benchmark:mae
npm run benchmark:demo
```

実行結果は新しい `results/<日時>-<suite>/` に保存。再試行はせず、API失敗時は停止し途中結果を残す。
`metadata.json` にデータ・リクエスト集合・ソースのSHA-256、モデル・閾値を記録。
初回は実装中の実行なのでgitDirty=true。コードの同一性は記録したソースハッシュで確認できる。
`predictions.jsonl` は全件のraw request/response、順位、正解ラベル、時間、推定コスト。
公開データ・自作答案のみを保存し、APIキーやAuthorizationヘッダーは保存しない。
`summary.json` にラベル別成績、混同行列、誤分類一覧、保留・速度・料金の集計を保存。
モデルの非決定性により再実行の数値は変わり得る。CIはAPIを呼ばない。
