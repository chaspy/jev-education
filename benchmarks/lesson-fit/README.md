# 授業の目的と問題の内容を照合する実験（やり直し）

問いは1つ。「先生の明示された目的に合う問題を、3候補＋該当なしから選べるか？」

検索や条件フィルターは使わない。全モデルへ同じ授業説明・依頼・3候補を渡す。
正解は単元タグではなく、問題文が要求する数学操作との一致。全候補の採点理由をcases.jsonに公開し、正解と理由をモデルには渡さない。
自作12場面（正解あり10、該当なし2）。各場面を依頼2表現×提示順2通りで試す。
48回は12場面の反復であり、独立した48事例とは数えない。

主指標は「4回全て正解した場面が12場面中いくつか」。補助的に全48回の一致数と該当なし・提示順の安定性を出す。
比較はJev、ローカルKev-0.5B、単純な文字bigram一致。ランダムなら期待値25%。
文字一致は単純な基準に過ぎず、強い検索システムや他LLMより優秀かは測れない。該当なし判定も文字一致ゼロの場合のみで、意味を見て棄却する機構はない。

これは内容照合能力の小さな実験。先生の時間短縮、2万教材の検索、学習効果は測らない。
教師が独立に採点した試験ではない。正解理由に異論があれば、そのケースを明示して改訂版として再評価する。既存結果の正解は書き換えない。

実行前にデータ・プロンプト・評価コードをcommitで固定する。モデル出力を見て調整しない。
実行: `node --env-file=.env benchmarks/lesson-fit/run.mjs jev` / `node benchmarks/lesson-fit/run.mjs kev`。
ログには公開例のrequestとresponse、時間、推定API料金を保存する。ローカルの機器費・電力費は含めない。
