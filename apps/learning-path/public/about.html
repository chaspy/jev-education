どうやって戻り先を選ぶ？

  1. Jev に問題・模範の途中式・入力された答案を渡し、最初の誤りの候補を選びます。
  2. 候補の確率と確信度が低い場合は保留します。しきい値はデモ用で、教育的妥当性を検証済みの基準ではありません。
  3. 候補の学習項目に対応する確認問題を出します。誤答なら復習候補を提示し、正答なら元の問題への再挑戦を案内します。
  4. 前提関係マップと教材の対応はコードで管理します。確認問題の正誤と再挑戦の数値照合もコードで処理します。

候補の確率は学習者の理解度・正解率ではありません。一度の誤答や一問の確認では、恒常的なつまずきは確定できません。成績評価・能力判定には利用しないでください。

入力と記録

入力した途中式は判定のため TypeSafe API に送信されます。氏名・連絡先・実際の生徒の答案・業務データは入力しないでください。TypeSafe 側の取り扱いは同社のポリシーに従います。

このアプリのサーバーログには実行ID、問題ID、判定ラベル、使用トークン数、所要時間、推定コスト、エラー種別を記録します。入力した途中式と認証情報はサーバーログに記録しません。ホスティング基盤ではアクセス情報が記録されることがあります。画面の request / response はリロードで消え、必要なら自分で JSON を保存できます。

料金と利用制限

Jev の実行は運営者の API キーを使用します。実行ごとの推定コストは入力トークン数から計算し、画面に表示します。2026-09-20確認の料金は jev-1.13.0 の入力100万トークンあたり $0.042、出力無料です。API 往復時間とブラウザー側の全体時間を別々に表示します。

公開デモのため連続実行を制限しています。IPごとに毎分10回、全体で毎分100回が各Cloudflare拠点の目安で、厳密な全世界の課金上限ではありません。確認問題・復習・再挑戦は API を呼びません。
