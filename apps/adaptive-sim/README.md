# 12年間の学びの旅

公開先: https://jev-education-adaptive-sim.take-she12.workers.dev

小学算数から高校数学までの代表36技能で、4人の架空生徒が練習・基礎確認・復習する624週間の記録を再生します。標準は1秒1週（10分24秒）。学年固定順、コードの復習ルール、Jevの候補選択を切り替えられます。

## データと再利用

- 学習指導要領LOD（元資料: 文部科学省） https://jp-cos.github.io/about 、CC BY 4.0 https://creativecommons.org/licenses/by/4.0/
- `public/curriculum.json` に取得日・元データSHA256・各技能の出典URIと引用を保存。原文から抽出、技能名・学年・前提関係を独自編集。高校の学年は独自配置で、公式の学年割当ではありません。
- `scripts/adaptive-sim/prepare.py` が公開TTLを取得し `skills.json` の指定を用いて作成。
- 問題・解答・解説・前提グラフは本デモの自作。これらの教材データは chaspy / jev-education を出典とするCC BY 4.0で提供。ソフトウェアのライセンスとは別です。
- 36種類のパラメータ付きテンプレートを数値変更して出題。全単元・全能力の網羅ではなく、証明や作図を扱いません。指導要領から学習の依存関係を自動取得したものでもありません。

## 何を検証しているか

観測した解答から候補を絞って渡せば、Jevを次の学習先の選択に組み込めるかを示す動作実験です。正解の復習先を採点するベンチマーク、実在の生徒に対する学習効果の検証ではありません。1つの乱数設定と自作モデルで、実行前に係数とプロトコルをcommit `5f2c9e1` に固定しました。

Jevには直近3週の正誤・問題と解答例・基礎確認結果・候補の累積解答数と確認度を渡します。生徒のタイプ、内部習熟、学習・忘却係数は渡しません。最大4候補の生成はコード、選択はJev。候補が1つのときはAPIなし。Jevの自由記述による理由生成は行っていません。

## 生徒モデルと指標

- 初期の内部習熟0.16。週に4問と、誤答があれば前提技能の確認を最大1問。確認問題でも解説を読む想定で学習します。
- 正解確率は `0.13 + 0.83 × 内部習熟 × (0.45 + 0.55 × 前提技能平均習熟) − 取り違え係数` を範囲内に制限。正誤は固定シードの乱数で生成。
- 各週に内部習熟を `exp(-忘却係数)` 倍に減衰。各問後に `学習係数 × 分野倍率 × (0.55+0.45×前提平均) × (1-習熟)` 分上昇。誤答後の解説は1.25倍。4タイプはこの係数の違いです。
- 観測の確認度は初期0.25、各問で `0.82×前回 + 0.18×正誤`。13週以上未確認だと週0.0015ずつ低下。
- **通過**: 累計8問以上かつ観測確認度0.74以上に一度到達。**最近確認**: 累計8問以上かつ現在の観測確認度0.68以上。技能を選ぶ方針により評価する問題も変わるため、この指標だけで学習効果の優劣を結論できません。
- **内部習熟**: シミュレータの隠れた値。表示切替で閲覧できますがJevには非公開。実際に測定した能力ではありません。
- **戻る**: 前週より手前の技能へ移動した回数。定期復習も含み、誤答原因の特定成功数ではありません。
- 共通シード・生徒/週/問題枠ごとの共通乱数を使用。方針で問題が変わり、以後の状態も変わります。

## 保存実行の結果

2026-09-20、jev-1.13.0、590 API呼び出し、2189選択。応答時間中央値252ms（ローカルからの往復）、入力トークン単価からの推定費用$0.103558。詳細は `data/summary.json`。

終了時の「最近確認」数（ソラ / アオイ / ハル / レン）:

|方式|ソラ|アオイ|ハル|レン|
|---|---:|---:|---:|---:|
|固定順|8|3|7|3|
|ルール|12|13|20|6|
|Jev|12|12|18|9|

Jevがルールを一貫して上回る結果ではありません。終了時の内部習熟0.7以上の数はJev 6/8/11/3、ルール7/9/15/3、固定順6/5/15/2。観測指標と隠れた習熟の差も、このモデルを評価する上での限界です。現実の検証には独立した共通到達度テストと実生徒データ、複数シード等が必要です。

## 再現と公開

```sh
npm run adaptive:dev
node --test apps/adaptive-sim/test/*.test.mjs
npm run adaptive:deploy
```

`node --env-file=.env scripts/adaptive-sim/run.mjs` は有料APIを呼ぶ生成処理です。既存ログがあると上書きせず停止します。再実行は別コピーで保存ログを退避して実施してください。公開サイトは保存済み記録を再生する静的アプリで、推論キーも生徒の私的データも不要です。

`data/jev-calls.jsonl` は全リクエスト・レスポンス・時間・推定料金、`data/jev-frames.jsonl` は生徒状態、`data/run-metadata.json` は実行時ファイルのハッシュ。公開用 `public/calls` はAPIログを年ごとに分割したものです。キー・認証ヘッダーは含みません。
